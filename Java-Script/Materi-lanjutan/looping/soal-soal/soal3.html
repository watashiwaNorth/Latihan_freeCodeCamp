Soal 3

Cerita:
Kamu memiliki daftar belanja berupa array: ["susu", "roti", "telur", "keju"]. Tampilkan setiap item dengan nomor urut. Instruksi:

  • Gunakan perulangan for...of untuk mengambil setiap item.
  • Gunakan variabel bantu untuk nomor urut (mulai dari 1) dan tambahkan setiap iterasi.
  • Cetak dengan format "1. susu", "2. roti", dst.
