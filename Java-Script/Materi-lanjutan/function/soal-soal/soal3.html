Soal 3

Cerita :
Aplikasi cuaca ingin memberikan rekomendasi pakaian berdasarkan suhu udara (dalam derajat Celsius).
Aturannya:
- Suhu < 10: "Jaket tebal dan syal"
- 10 ≤ suhu < 20: "Jaket ringan"
- 20 ≤ suhu < 30: "Kemeja atau kaos"
- Suhu ≥ 30: "Pakaian berbahan adem dan minum banyak air"
Buat function rekomendasiPakaian(suhu) yang mengembalikan rekomendasi tersebut.

Intruksi

  • Buat function rekomendasiPakaian(suhu).
  • Gunakan if-else if untuk menentukan rekomendasi berdasarkan suhu.
  • Kembalikan string rekomendasi.
