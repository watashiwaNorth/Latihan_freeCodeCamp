Soal 2

Cerita:
Sebuah bioskop memberlakukan harga tiket berdasarkan kategori umur penonton.
Kategorinya adalah:
- Anak-anak (umur < 12): Rp 25.000
- Remaja (12 ≤ umur < 18): Rp 35.000
- Dewasa (18 ≤ umur < 60): Rp 50.000
- Lansia (umur ≥ 60): Rp 30.000
Buat function hargaTiket(umur) yang menerima umur penonton dan mengembalikan harga tiket sesuai kategori.

  • Definisikan function hargaTiket(umur).
  • Gunakan if-else if untuk mengecek umur dan mengembalikan harga yang sesuai (dalam number).
  • Uji dengan beberapa umur dan cetak hasilnya.
