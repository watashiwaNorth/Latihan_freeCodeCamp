Cerita:
Sebuah aplikasi ramalan ingin menampilkan zodiak berdasarkan tanggal lahir pengguna.
Zodiak ditentukan dari bulan dan tanggal.
Buatlah function tentukanZodiak(tanggal, bulan) yang menerima dua parameter: tanggal (1–31) dan bulan (1–12). Aturannya sebagai berikut:

  • Buat function tentukanZodiak(tanggal, bulan).
  • Gunakan if-else untuk membandingkan bulan dan tanggal, lalu kembalikan nama zodiak.
  • Uji function dengan beberapa tanggal lahir dan cetak hasilnya.
