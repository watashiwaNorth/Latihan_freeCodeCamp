Soal 3

Cerita:
Seorang desainer grafis ingin membuat efek teks terbalik untuk judul. Diberikan string "Januari,Februari,Maret", ia ingin mengubahnya menjadi array, membalik urutan elemen, lalu menggabungkannya kembali dengan spasi.

Instruksi:

  1. Buat variabel bulanString berisi "Januari,Februari,Maret".
  2. Ubah menjadi array dengan split(",").
  3. Balik urutan array menggunakan reverse().
  4. Gabungkan array menjadi string dengan pemisah spasi " ".
  5. Tampilkan array setelah dibalik, lalu string hasil penggabungan.
