Soal 2

Cerita:
Sebuah aplikasi sensor ingin memeriksa apakah kata "merah" muncul dalam kalimat "Bendera kita berwarna merah putih".
Aplikasi juga ingin mengubah kalimat menjadi array kata untuk analisis lebih lanjut.
Instruksi:

  • Buat variabel kalimat berisi "Bendera kita berwarna merah putih".
  • Ubah kalimat menjadi array kata dengan split(" ") dan simpan dalam kataArray.
  • Periksa apakah array kataArray mengandung kata "merah" menggunakan metode includes().
  • Tampilkan array kata, lalu hasil pemeriksaan (boolean) dengan format "Apakah ada kata 'merah'? true/false".
