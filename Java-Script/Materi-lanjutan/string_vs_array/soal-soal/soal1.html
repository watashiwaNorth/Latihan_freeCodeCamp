Soal 1

Cerita:
Seorang ibu rumah tangga menulis daftar belanja dalam satu baris: "susu,roti,telur,keju".
Namun, dia ingin mengubahnya menjadi array agar bisa menambah atau menghapus item dengan mudah.
Setelah itu, dia ingin menggabungkannya kembali menjadi string dengan pemisah " - ".
Instruksi:

  • Buat variabel daftarString berisi string "susu,roti,telur,keju".
  • Ubah string tersebut menjadi array menggunakan split(",") dan simpan dalam daftarArray.
  • Tambahkan item "mentega" ke akhir array dengan metode push().
  • Gabungkan kembali array menjadi string dengan pemisah " - " menggunakan join(" - ").
  • Tampilkan array setelah penambahan, lalu string hasil penggabungan.
